# Titan documentation

Docusaurus site for the Titan template.

> Status: docs rewrite in progress. `docs/` is empty and the docs plugin is
> temporarily disabled (`docs: false` in `docusaurus.config.ts`). The site
> currently serves only the landing page and 404 until the new IA lands.

## Commands

Run from this folder (`documentation/`):

```bash
pnpm install --frozen-lockfile
pnpm start        # local preview
pnpm build        # production build, broken links throw
pnpm typecheck    # tsc
```

`pnpm lint:md` and `pnpm spell` have no files to check while `docs/` is
empty. Run them again once the first pages land.

Or from the repo root: `pnpm docs:dev`, `pnpm docs:build`.

## Re-enabling docs

1. Add the first pages under `docs/` (start with `docs/intro.md`).
2. In `docusaurus.config.ts`: set `docs: {sidebarPath: './sidebars.ts',
   editUrl: 'https://github.com/HuyThang011104/expo-template-titan/tree/main/documentation/'}`,
   restore the `docSidebar` navbar item, footer `/docs/*` columns,
   `docusaurus-plugin-llms`, and per-page client redirects.
3. In `sidebars.ts`: list every new page deliberately by hand — never switch
   back to autogenerated.
4. In `src/pages/index.tsx` and `404.tsx`: point CTAs back at `/docs/*`.

## Conventions (apply once docs return)

- Every page needs frontmatter with `sidebar_position` and a `description` under 160 characters. The H1 must be a clean title with no `ADR 000X:` style prefix.
- New pages must be placed deliberately in `sidebars.ts` — never switch back to autogenerated.
- Never copy config values into prose. Link to the source instead: `app.config.ts`, `eas.json`, root `package.json`, `packages/create-expo-titan/src/placeholders.js`.
- Internal links use relative paths (`./`, `../`) and must resolve — the build throws on broken links.
- Deleted or moved pages need a redirect in `docusaurus.config.ts` (`@docusaurus/plugin-client-redirects`) because the site is already deployed.
- Unknown spell-check words go into `cspell.json` only if they are real project terms.
